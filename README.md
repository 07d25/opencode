# opencode

Refero de aprendizaje. Cada proyecto vive como carpeta en `main`:

- **`01-OpenCode101/`** — Página web de introducción a OpenCode.
- **`02-app-de-consola/`** — Weather CLI con arquitectura por capas y suite de tests (TypeScript + Bun).
- **`03-asteroids/`** — Clon de Asteroids en canvas HTML5; incluye los power-ups Triple Shot, Skins y Shields (fusionados de las ramas `01-triple-shot`, `02-skins` y `03-shields`; `skins-globales` quedaba ya incluido en esta rama).
- **`open-pacman/`** — Clon de Pac-Man con laberinto 28×31 (proyecto Spec Driven Development, proveniente de la rama `04-spec-driven-development-design-(skills)`).
